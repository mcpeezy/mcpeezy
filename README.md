## Engineering kits

Patterns generalized from paid engagements:

- [supabase-ledger-hardening-kit](https://github.com/epiphany-dynamics/supabase-ledger-hardening-kit): concurrency-safe ledger, RLS audit tool, load tests
- [call-speaker-diarization-kit](https://github.com/epiphany-dynamics/call-speaker-diarization-kit): voiceprint speaker identification on shared phone lines
- [nocode-email-fallback-kit](https://github.com/epiphany-dynamics/nocode-email-fallback-kit): webhook-to-Resend fallback for no-code email that silently fails
- [resilient-data-source-kit](https://github.com/epiphany-dynamics/resilient-data-source-kit): scraper backoff, circuit breaking, fuzzy entity matching
